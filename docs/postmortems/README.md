# docs/postmortems

Blameless postmortems for incidents, written with the template in [TEMPLATE.md](TEMPLATE.md).

## Status

Planned

## Responsibilities

- One file per incident, named `YYYY-MM-DD-slug.md`.
- Focus on systems and decisions, not individuals.
- Each postmortem ends with action items.

# docs/api

Entry point for the HTTP API documentation. The source of truth is the OpenAPI documents in `contracts/openapi`; this folder only links to them and describes conventions.

## Status

Planned

## Responsibilities

- Links to each service's OpenAPI document.
- Conventions: JSON bodies, bearer JWT authentication, `GET /health`, `POST /sandbox/reset`, integer minor-unit money fields.

# architecture/diagrams

Home for non-C4 diagrams such as sequences, flows and state machines. Mermaid is preferred so that diagrams stay in version control as text.

## Status

Planned

## Responsibilities

- One Markdown file per diagram topic, or diagrams embedded in ADRs.
- Diagrams are validated with Mermaid CLI before a pull request is merged, where possible.
